# Extract forecasts from a summarised posterior

Uses the `observed` variable returned by
[`fv_tidy_posterior()`](epiforecasts.io/forecast.vocs/reference/fv_tidy_posterior.md)
to return posterior predictions for forecast dates only.

## Usage

``` r
fv_extract_forecast(posterior)
```

## Arguments

- posterior:

  A dataframe of posterior output as produced by
  [`fv_tidy_posterior()`](epiforecasts.io/forecast.vocs/reference/fv_tidy_posterior.md).
  For forecast dates to be extracted data with `value_type == "cases"`
  must be present.

## Value

A `data.frame` of forecasts in the format returned by
[`fv_tidy_posterior()`](epiforecasts.io/forecast.vocs/reference/fv_tidy_posterior.md)
but with fitting variables dropped.
